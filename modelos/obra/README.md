# Modelo de caso de obra — arquivo de trabalho

`ModeloDeCaso.tsx` preserva integralmente a antiga página demonstrativa. Está fora de `app/` e não cria uma rota nem é exportada para o site público.

Para apresentar o primeiro caso real, usar `components/CaseStudy.tsx` e o contrato de `lib/case-studies.ts`. Preencher somente fatos documentados e imagens autorizadas. Criar a rota comercial quando esse conteúdo estiver aprovado; não publicar os exemplos como obra executada.
